# Financial Report Analyzer

A data-heavy financial-report analysis application for turning uploaded portfolio statements into structured, visual insights.

## What it explores

- Upload-driven financial analysis workflows
- Structured parsing of PDF, Excel, and CSV inputs
- Asset-allocation summaries and comparison views
- Fund and portfolio tables with export-oriented layouts
- Clear presentation of complex financial information

## Design approach

The interface follows a professional, data-first visual system: focused upload flow, responsive tables, allocation cards, charts, sticky navigation, and clear export actions.

## Stack

React, TypeScript, Express, PostgreSQL, Drizzle ORM, Tailwind CSS, Recharts, and Python utilities for data preparation.

## Status

This is an alternate Financial Friend report-analyser codebase and design iteration. It is kept as a separate implementation for comparison and continued product development.
